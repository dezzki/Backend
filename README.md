# Backend Speed Run 🏁

Learning backend from scratch, one topic a day with small videos, immediate projects.

## How I plan to learn

- **1 topic = 1 day**, videos (~1hr) that cover the essentials
- **Learn the minimum, then build** I try to pick up advanced stuff naturally while building projects.
- **Every topic ends with a working project**  watching without building doesn't stick
- **AI helps with the code explaining and understanding, I build the architecture** I review and understand everything line by line
